\# JARVIS — Local AI Desktop Assistant



JARVIS is a modular AI desktop assistant powered by local LLMs using Ollama and Python.



\## Features



\- Local LLM support with Ollama

\- Browser automation

\- Workflow engine

\- Event-driven architecture

\- File organization

\- Desktop automation

\- Voice/text command support

\- Async orchestration



\## Tech Stack



\- Python

\- Ollama

\- AsyncIO

\- PyAutoGUI

\- Tesseract OCR

\- Event Bus Architecture



\## Commands



\- Open applications

\- Search the web

\- YouTube search

\- Organize downloads

\- Internship workflows

\- Browser automation



\## Architecture



JARVIS uses:

\- Orchestrator

\- Workflow Engine

\- Tool Registry

\- Event Bus

\- Browser Router



\## Future Plans



\- Overlay HUD

\- Screen understanding

\- Persistent memory

\- Autonomous workflows

\- Voice streaming



\## Run



```bash

python main.py --text
```
