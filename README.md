# JARVIS — Local AI Desktop Assistant

JARVIS is a modular AI desktop assistant powered by local LLMs using Ollama.

Features:
- Local AI inference
- Browser automation
- Workflow engine
- Event-driven architecture
- Desktop automation
- File management
- Tool registry system
- Async orchestration

Tech Stack:
- Python
- Ollama
- AsyncIO
- PyAutoGUI
- Tesseract OCR
- Event Bus Architecture

## Features

- Open applications
- Web search
- YouTube search
- Internship workflows
- Organize downloads
- Browser automation
- Voice/text command support

## Architecture

JARVIS uses:
- Orchestrator
- Workflow Engine
- Tool Registry
- Event Bus
- Browser Router
